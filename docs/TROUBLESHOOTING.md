# 常见问题与排障（TROUBLESHOOTING）

## Web 应用

### 刷新后课表没了？
数据保存在浏览器 IndexedDB 中。以下情况会清空：
- 浏览器清除站点数据 / 隐私模式；
- 换了浏览器或设备（数据不跨设备同步，属预期）。

恢复方式：设置 → 导出全部数据（提前备份），或重新导入 `.campusschedule.json`。

### 显示"示例课表数据"？
首次使用会自动写入示例课表便于体验。导入真实课表后自动替换。

### "当前周"不对？
当前教学周 = （今天 − 学期开学周一）/ 7 + 1。请到学期管理确认
"学期第一教学周起始日期"是否正确（必须是周一日期，格式 YYYY-MM-DD）。

### 导出 ICS 后部分课缺失？
某节次缺少作息时间定义时该课会被跳过并在结果中说明。
作息时间必须来自学校官方校历或手动配置，应用不会编造时间。

## 扩展（CampusSchedule Importer）

### 安装
1. 打开 Chrome/Edge → `chrome://extensions`；
2. 开启"开发者模式"；
3. "加载已解压的扩展程序" → 选择 `apps/extension/dist/` 目录
   （或解压 `dist/extension/campusschedule-importer.zip` 后选择）。

### 页面右下角没有调试面板？
- 确认当前页面域名属于 `*.gdipu.edu.cn`（扩展只申请了该校域名权限）；
- 刷新页面（content script 在 `document_idle` 注入）。

### 面板显示"登录页（禁止解析）"？
页面存在密码输入框。请先自行完成登录，再回到课表页面。
扩展不读取任何输入内容。

### 点击"解析并导出"提示 BLOCKED_BY_REAL_PAGE_FIXTURE？
属预期：GDIPU 课表解析器尚未完成真实页面适配。
请点击"生成脱敏课表快照"，确认脱敏预览后下载，并提交给开发者作为适配依据。

### 导入 Web 端时提示"数据校验失败"？
- 确认文件是扩展导出的 `.campusschedule.json`（不是快照 HTML 或 debug JSON）；
- 扩展版本与 Web 版本协议需一致（当前协议 v1）。

### 提示"新课表数据量异常"？
新导入的课表时段数量比本地骤降（低于一半），可能是教务页面结构变化
导致解析不完整。请核对预览内容，确认无误后勾选确认才可覆盖。

## 隐私相关

- 应用不保存学校账号、密码、验证码、Cookie、Token；
- 快照导出前自动移除脚本、表单值、事件属性，并把长数字串（学号/电话）替换为 `[STUDENT_ID]`；
- 快照仍可能包含姓名等文本，请务必在下载前预览确认；
- 来源 URL 在保存/导出前会移除 token/ticket/session 等敏感参数。
